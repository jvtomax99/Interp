# Brief template

Copy this file for a new film. Fill in BRAND. Change the others only if
you need to. Give the filled copy to Claude and say: "Build this film,
the way promo/blender/README.md does."

## BRAND (the only block you must change)

- **Hero:** who moves. A real picture or a simple shape. Say which files.
- **App:** the screen the hero works on. Name every panel and every
  button. Real labels, no real logos.
- **Result:** what the hero builds. Every button press must change
  something you can see.
- **Set:** where it all floats. One colour, one mood.

## FORMAT

Size (1280 x 720 is fine), 30 frames per second, how many seconds, the
beat speed (120 BPM = one beat every half second).

## BEATS

A table. One row per moment: the second it happens, what the hero does,
what changes on the result.

## CAMERA

Where it starts, what it follows, where it ends.

## LOOK

The light, the glass, the colours that must come out exact.

## CHECKS

Test pictures first, a grid of stills second, the full film last.

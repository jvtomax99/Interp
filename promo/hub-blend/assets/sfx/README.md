# Sound effects

From Damiano Caudullo's "Motion Graphics with Claude Code" starter kit
(instagram.com/damianodesu), which says of them: "9 sound effects, made in
code. Use them anywhere." 48 kHz mono WAV.

The promo uses tick, snap, success, counter and chime (`tools/sfx.cjs`); the
other four (fill, pop, star, switch) are here for later.

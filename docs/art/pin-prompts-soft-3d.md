# Pin prompts: Soft studio 3D (Jose's pick, 2026-11-03)

Paste one sheet at a time into the same image tool that made the examples.
Paste the STYLE block first, then that sheet's list. Make all four sheets in
the same chat, so the tool keeps the look the same. Send the four pictures
back here; Claude cuts each pin out, cleans it, saves it as `pins/<key>.webp`
and checks it on Home.

## STYLE (paste before every sheet)

```
A sheet of app icons in one consistent "soft studio 3D" style, for a
medical interpreting app with a calm, premium iOS look.

Layout: a grid of 4 columns and 3 rows, every icon centered in its own
square cell, all icons the same size (each fills about 85% of its cell),
generous even spacing, nothing touching or crossing into another cell.
No labels, no captions, no cell borders.
Background: transparent (if not possible, plain flat white #FFFFFF, no
gradient, no texture).

Look: smooth rounded 3D shapes like soft vinyl toys, satin finish, gentle
highlights, no outlines, no gold rims, no text unless listed. No faces on
organs or objects; people and the teddy bear get simple, friendly faces
(small dark eyes, a gentle smile).
Soft studio light from the top left. A very soft shadow below each icon,
tinted navy blue (never black or gray). Same slight 3/4 camera angle for
every icon. Simple, bold silhouettes that are still clear at 32 pixels.

Colors only from this palette: coral red #E5566B, sky blue #2E8BD0,
deep blue #0F5FA6, cyan #01B8E6, lilac #9B7FD6, teal #2BB59A,
warm cream #F6EBDD, soft white #FAFBFD, navy accents #252E6D,
sunny yellow #F5B83D, soft pink #F28DB2. Skin tones warm and natural.
```
